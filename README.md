# 👁️ Iris Disease Recognition System  

## 📌 Overview  
A web-based application to detect and classify iris diseases using **Machine Learning**.  
Built with a Flask backend and HTML/CSS frontend.  

## 🛠️ Tech Stack  
- Python, Flask  
- HTML, CSS, Bootstrap  
- SQL (Data Management)  
- AJAX & JSON for seamless communication  

## ✨ Features  
- User-friendly web interface  
- Image classification of iris diseases  
- Secure data management with SQL  
- Integrated AJAX for smooth frontend-backend flow  

## 📂 Project Duration  
📅 May 2023 – Oct 2023
